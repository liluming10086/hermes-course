# Hermes 实操课

一门面向 AI 初学者的 Hermes Agent 实操课程。不讲"有哪些功能"，讲**遇到任何 Agent，怎么判断该配什么、配在哪、值不值得配**。

12 章 + 3 个附录，每章结构统一：**为什么（理论）→ 一句话类比 → 现在动手（可复制命令）→ 自检清单 → 常见坑**。

## 内容

| 部分 | 章节 |
|---|---|
| 一 · 心智模型 | 起点诊断 / Agent 到底是什么 / 五层配置地图 |
| 二 · 四个入口 | SOUL.md 性格 / memory 事实 / AGENTS.md 项目 / SKILL.md 技能 |
| 三 · 采购与编排 | 插件采购学 / 五种编排姿势 / 三个场景配方 / 自进化闭环 |
| 四 · 外观与工作台 | 皮肤与桌宠 / 桌面插件与管理台 |
| 附录 | 命令速查 / 30 天路线 / 参考资料 |

## 打开方式

直接双击 `index.html`，或起一个本地服务：

```bash
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899
```

## 结构

```
index.html          生成产物：单文件网页（CSS/JS 内嵌，无外部依赖）
content.html        内容源：hero + 16 个 <section>，只放正文
build.py            构建脚本：注入阅读时长、上下翻页、生成侧栏目录
new-chapters.html   第 11、12 章的原始草稿（已并入 content.html）
index-v1.html       第一版备份
```

改内容改 `content.html`，改样式/功能改 `build.py` 里的 `CSS` / `JS` 常量，然后：

```bash
python build.py
```

## 特性

- 侧栏目录 + 全站搜索 + 键盘 ←/→ 翻章
- 顶部阅读进度条、每章预计时长、勾选完成度（localStorage）
- 深浅色手动切换，跟随偏好
- 打印样式：每章自动分页，可直接打印成 PDF
- 中文全部走系统字体，无外部字体/脚本依赖，离线可用

## 适用范围

课程里的命令与配置项对应 Hermes Agent（Nous Research）2026 年中版本。换用其他 Agent（Claude Code、Codex、Cursor）时，心智模型部分（分层配置、指令预算、渐进披露、验证习惯）依然成立，具体命令需要替换。

## 许可

内容仅供个人学习使用。
